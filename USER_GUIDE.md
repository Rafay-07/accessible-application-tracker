# Co-op Application Tracker: user guide

This guide shows you how to track job applications with the tracker. It takes about two minutes to learn.

## Open the tracker

1. Download or clone the project.
2. Open `index.html` in any web browser. No installation or account is needed.
3. Your applications are saved in your browser. They stay there until you delete them or clear your browser data.

## Add an application

1. Type the company name in **Company**. This field is required.
2. Type the job title in **Role**. This field is required.
3. Optional: choose a **Deadline**.
4. Choose a **Status**. The default is "Not applied".
5. Select **Add application**.

If you leave Company or Role blank, a red message appears under the field and the cursor moves to it so you can fix it.

## Find an application

- **Filter by status:** choose a status, such as "Applied", to see only those applications. Choose "All" to see everything again.
- **Search:** type part of a company name or role. The table updates as you type.
- The line above the table tells you how many applications are showing.

Applications are always sorted by deadline, soonest first. Applications with no deadline appear last.

## Update or delete an application

- To change a status, choose a new one in the **Status** column of that row. The change saves right away.
- To remove an application, select **Delete** in its row. This cannot be undone.

## Use the tracker with a keyboard or screen reader

- Press **Tab** to move between fields and buttons, and **Shift + Tab** to move back.
- The first Tab press shows a **Skip to main content** link. Press **Enter** to jump past the header.
- Every field has a visible label, and the focused element has a yellow outline.
- Screen readers announce changes, such as "Application added" or "Showing 2 of 3 applications".

## Troubleshooting

| Problem | Fix |
|---|---|
| My applications disappeared | They are saved in one browser on one computer. Check that you are using the same browser, and that you did not clear browsing data. |
| Nothing saves in a private window | Private windows often block saved data. Use a normal window. |
